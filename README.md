# scoop-bucket

[Scoop](https://scoop.sh) bucket for [melange](https://github.com/pthm/melange), an OpenFGA to PostgreSQL compiler.

```powershell
scoop bucket add pthm https://github.com/pthm/scoop-bucket
scoop install pthm/melange
```

Manifests are published automatically by the melange release workflow.
